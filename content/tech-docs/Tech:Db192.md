**db192** is a FiberState server in Salt Lake City, Utah running Debian Trixie. It is a Database server running [MariaDB](/tech-docs/techmariadb). It currently exclusively hosts the databases for Miraheze Meta, [Miraheze Commons](https://meta.miraheze.org/wiki/commons:), [Miraheze Login Wiki](https://meta.miraheze.org/wiki/mh:login:), the [CentralAuth database](https://meta.miraheze.org/wiki/mw:Extension:CentralAuth), and the [Incidents database](https://meta.miraheze.org/wiki/Special:IncidentReports).
