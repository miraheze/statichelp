title: Tech:WikiTideDebug
---

WikiTideDebug is a browser extension that allows for conveniently debugging issues that:
* Emit an error backtrace but you don't want to wait for Graylog to record it.
* Occur only on a specific MediaWiki server.

## Install 

Install it through:
* [Chrome Web Store](https://chromewebstore.google.com/detail/wikitidedebug/labnadhpdnkcadngfkfcpkhlgffchapc)
* [FireFox Browser Add-On](https://addons.mozilla.org/en-US/firefox/addon/wikitidedebug/)

## Usage 

Retrieve the access key from [https://issue-tracker.miraheze.org/K34](https://issue-tracker.miraheze.org/K34) and paste it into the extension's input box.
