**mwtask151** is a FiberState server in Salt Lake City, Utah running Debian Trixie. It is a [MediaWiki application server](/tech-docs/techmediawiki_appserver) which is responsible for heavy and intensive MediaWiki tasks (e.g. maintenance scripts, imports). It is not web accessible but is publicly exposed.
